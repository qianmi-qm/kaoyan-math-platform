# 题库内容说明

## 当前数据

- 题库共 **31 道题**（1 道早期演示题 + 30 道原创仿真题）
- 30 道原创仿真题：10 道单选、10 道填空、10 道大题
- 覆盖知识点：极限、导数、积分、换元法、分部积分、洛必达法则、中值定理、多元微分、级数、微分方程

原始数据文件：[`original-30-questions.xlsx`](original-30-questions.xlsx)

## 为什么是原创仿真题

近五年数学一/数学二真题及第三方解析属于有版权的汇编内容。当前题库**不包含**从网上抓取的真题原文或第三方解析，避免商业产品中的版权风险。

这些题是：

- 按考研高数常见考点和难度原创编写
- 答案与解析自写
- 题干、数字、设问均为独立表达
- 解析统一带 `【原创仿真题】` 标记

## Excel 导入格式

第一行为表头，列顺序固定：

| 列 | 字段 | 说明 |
|---|---|---|
| A | 题干 | 支持 `$...$` LaTeX |
| B | 题型 | 1 单选 / 2 填空 / 3 大题 |
| C | 选项 | JSON 数组，如 `["A. $0$","B. $1$"]`；填空/大题留空 |
| D | 答案 | 单选填 A/B/C/D；填空填可判分答案；大题填最终答案 |
| E | 解析 | 可空；建议写完整步骤 |
| F | 难度 | 1 易 / 2 中 / 3 难 |
| G | 知识点 | 逗号分隔的已存在知识点名 |

导入入口：管理员登录 → 题库 → 批量导入 Excel。

## 扩展到真题时

如果后续拿到**书面授权**或开放许可的真题数据：

1. 保留年份、科目、题号、来源、授权备注
2. 只导入获得授权的题干
3. 答案和解析自己校验/自写
4. 先导入一套试点，人工抽检公式和答案
5. 确认无误后再批量导入

不要把“网上免费下载”直接当作可商用授权。
